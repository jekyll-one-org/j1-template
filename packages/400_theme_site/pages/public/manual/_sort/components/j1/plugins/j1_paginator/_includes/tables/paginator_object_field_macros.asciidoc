
.Paginator object field macros
[cols="2a,3a,7a", options="header", width="100%", role="rtable mt-4"]
|===
|Macro |Replaced by |Example

|`:title`
|original page title
|Page with `title: "Index"` and paginate
config `title: ":title - split"` becomes `<title>Index - split</title>`

|`:num`
|number of the current page
|Page with `title: "Index"` and
paginate config `title: ":title (page :num)"` the second page becomes
`<title>Index (page 2)</title>`

|`:max`
|total number of pages
|Page with paginate config
`title: ":num of :max"` the third page of 10 will become
`<title>3 of 10</title>"`

|===
